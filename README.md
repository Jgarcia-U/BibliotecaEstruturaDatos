# Sistema de Gestión de Biblioteca

Proyecto desarrollado en Python usando estructuras de datos lineales y una interfaz gráfica con Tkinter.

Este sistema permite administrar libros y usuarios de una biblioteca, soportando las operaciones básicas de:

- Agregar libros
- Agregar usuarios
- Prestar libros
- Devolver libros
- Manejo de historial de préstamos
- Lista de espera (cola)
- Seguimiento de libros prestados (listas)
- Registro de operaciones recientes (pila)

Este proyecto fue desarrollado aplicando los conceptos de la Unidad 1 del curso de **Estructuras de Datos**.

## Tecnologías utilizadas

- **Python**
- **Tkinter** (interfaz gráfica)
- **Colecciones de Python (`deque`)** para colas
- **Listas** utilizadas como pilas y como repositorio de objetos

## Instalación y requisitos

Asegúrate de tener Python instalado.

python --version
